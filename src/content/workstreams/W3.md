---
id: W3
title: "Continual learning: hard freezing"
tagline: Can freezing each task's most important units let one network learn many tasks?
---

This is the first of our two continual learning approaches. After a task is learned, we keep its most important units, freeze them so that no later task can change them, and give the rest of the network to the next task. Forgetting is impossible by construction. The real questions are how much accuracy each task keeps, and how much of the network each task uses up.

The best-known method of this kind, PackNet, picks the units to keep by weight magnitude. Our version makes the choice swappable, so we can compare functional connectivity scores, magnitude, Taylor importance and random choice at equal capacity, on Split-MNIST and Split-CIFAR-10. Given what we found in W2, we expect magnitude to be hard to beat. The interesting question is whether continual learning rewards something that single-task pruning does not.

This work starts in December 2026, in the [ASF-S_Hard_Freezing](https://github.com/NeuroPulse-Co/ASF-S_Hard_Freezing) repository.
