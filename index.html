BSc Eng (Hons) Final Year Project · Project Proposal

Structure-Function-Aware Pruning
for Continual Learning

A replay-free, fine-tuning-free continual learning framework that isolates task subnetworks by their functional importance rather than raw weight magnitude — enabling neural networks to learn new tasks over a lifetime without forgetting old ones, and without the retraining overhead that keeps lifelong learning off resource-constrained edge devices.

The Problem, in Brief

Problem

Magnitude pruning ignores function

Existing parameter-isolation methods zero out weights closest to zero, ignoring the functional dependencies and gradient topology that actually drive predictions — risking the removal of structurally vital pathways.

Bottleneck

Retraining doesn't scale to the edge

Recovering accuracy after pruning demands multi-epoch fine-tuning after every task — computationally infeasible for battery-powered, thermally-constrained edge hardware learning continuously on-device.

Rigidity

Static allocation wastes capacity

Fixed pruning ratios treat every task identically — starving complex tasks of capacity while wasting it on simple ones, causing networks to saturate prematurely over long task streams.

Two Proposed Approaches

Both build on Artificial Structure Function Search (ASF-S) and Principal Gradient Importance (PGI) to extract task subnetworks in a single shot — no post-pruning fine-tuning loops.

01

Hard Freezing via ASF-S

A baseline adaptation of ASF-S to task-incremental continual learning: static top-p% subnetwork selection by PGI score, with binary hard freezing of consolidated parameters.

02

Metaplastic Soft Framework Proposed

Dynamic subnetwork sizing via cumulative variance thresholding (τ), soft metaplastic learning-rate decay instead of hard freezing, and Huffman-compressed task bitmasks for sub-linear memory growth.
